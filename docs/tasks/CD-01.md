# CD-01：达人详情数据展示与 UI/UX 优化

状态：待验收  
更新时间：2026-10-14T15:10:00+08:00  
是否验收：部分；详情 UI 实现、Lazyweb MCP 实际检索、静态/单元/前端与真实 Chrome 页面验收通过；隔离 PostgreSQL 集成测试库当前不可连接。

## 目标与范围

实现用户确认的《达人详情页面产品设计方案》：让 MCN 媒介可在任务快照或达人库当前资料中完成达人基础、商业、内容、连接用户、种草转化、履约、报价、历史与数据来源的分层阅读。保留 JSONB 作为权威来源，任务入口继续读取不可变快照，达人库入口继续读取当前资料。

包含：统一详情 API 表达、详情页面信息架构、复杂 JSONB 数据渲染、数据状态与来源展示、前后端测试及 Playwright Chrome 验收。

不包含：采集契约、采集流程、平台口径猜测、达人评分/比较/收藏/邀约/CRM、跨平台合并。数据库追加式保护、历史索引补齐等 LIB-01 数据治理项仅在详情实现被现有读取能力阻断时纳入，其他部分保持独立。

## 关联与依赖

依据 [开发规范](../agent.md)、[技术方案](../AI达人智能发现与采集系统-完整技术方案.md) 的 F05/F06、数据保留和产品 API 章节；前置 [DATA-01](DATA-01.md)；复用并不覆盖进行中的 [LIB-01](LIB-01.md) 和待验收 [UI-01](UI-01.md) 改动。
