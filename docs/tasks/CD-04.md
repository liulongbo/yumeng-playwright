## 目标与范围

把「达人详情 → 商业能力」从"字段分区堆叠"重构为媒介可用的四块业务结构，并完成字段联通、格式化与视频卡片：

1. **传播价值**：内容数据（7 项）、性价比/效果预估（6 项）、优秀传播视频（`excellent_reach`）
2. **种草价值**：6 项指标（含 6 处改名）、优秀种草视频（`excellent_seeding`）
3. **转化价值**：5 项指标（含 3 处改名，区间原值保留）

**用户后续调整（2026-10-15，本轮内已执行）**：从「商业能力」中**去掉** ①「报价明细」模块、②「历史合作行业」模块；商业能力只保留 传播价值 / 种草价值 / 转化价值 三块。报价数据未被删除——任务入口的报价改由该入口自己的「报价与历史」章节承载，达人库入口保留原「报价与历史」章节（详见"实现记录"末段）。

包含：商业能力章节组件重构、字段映射与格式化（万元/k、万分比百分位、秒×100）、视频卡片与作品跳转、达人库入口的精选集合只读端点、局部样式、测试与真实浏览器验收。

不包含：采集契约与解析、Scheduler/Queue/Worker、登录会话、数据库 Schema 与迁移、未采集字段的补采（进店成本、预期播放量、爆文率）、其他章节的大规模重构。**未执行任何数据库 Schema 修改、迁移或数据回填。**
