## 最小修复（本次真实发现）

**现象**：02:14 预算暂停留下 1 位 `7623704992305643547` 仅完成 basic；任务达到 70 valid 后以 PARTIAL_COMPLETED 结束（profile 69），但 `allowed_actions=[]`、`retry_plan.retryable_creator_count=0`，无法补采。

**根因**：`retry_policy.is_retryable` 只检查已存在模块的 `complete`，不检查 checkpoint `profile_module_keys` 中缺失的预期模块。

**修复**：`is_retryable` 支持 `expected_modules`；`retryable_creator_count`/`requeue_for_retry`/`Repository.retryable`/`allowed_actions`/retry 调用传入 `profile_module_keys`；新增缺失模块保护单测。涉及共享 retry policy，仅增量判定，不改变既有 failed/incomplete 语义。

**文件**：`backend/src/xingtu/retry_policy.py`、`backend/src/xingtu/repository.py`、`backend/src/xingtu/product_queries.py`、`backend/tests/unit/test_retry_policy.py`。

**复测**：重启 API 加载修复（任务已终态）→ 同一任务 retry backfill 1 位 → 03:22 **COMPLETED**、70/70 complete；旧中断快照保留，新快照/current 指向完整版本。
