# UI-01：前端页面优化（登录密码可见性、导航菜单、任务内达人、完成时间、达人详情统一）

状态：待验收
更新时间：2026-10-14T11:20:00+08:00
是否验收：否；五项需求均已实现并通过真实 Chrome 页面级验收与静态/自动化检查，但"任务从创建到终态"的完成时间写入尚未在真实采集链路中验证（本轮未发起真实采集），且 Playwright MCP 为 stdio 客户端代调而非工具直调。

## 目标与范围

交付 5 项前端页面优化，且不改变既有采集链路与后端数据语义：

1. F01 登录页密码显示/隐藏切换。
2. 首页导航菜单移除与任务中心重复的「创建任务」入口，并调整间距。
3. 「任务中心 → 任务详情 → 任务内达人」按达人库口径补齐达人信息展示。
4. 澄清「最近更新」含义，并新增任务级「完成时间」字段与展示。
5. 「任务中心 → 达人详情」与「达人库 → 达人详情」统一为同一套展示。

包含：上述页面、组件、路由与展示逻辑；`root_tasks.completed_at` 最小新增字段；对应前后端测试与验收脚本。

不做：采集/解析/标准化/去重/持久化逻辑、LangGraph Workflow、Scheduler/Worker/Queue/ExecutionUnit、自动化浏览器采集、达人库读模型、任务状态机判定条件、平台契约与生产线路。

## 关联与依赖
