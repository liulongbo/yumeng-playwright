## 目标与范围

交付独立达人库：以 `platform_creators.projection` 为当前值、以 `creator_snapshots.payload` 为历史事实，新增抖音星图结构化查询索引、受认证保护的 API 与 React 列表/详情页面。支持行业、类型、地区、粉丝、月涨粉、互动/完播/CPM/CPE 原始值筛选，合作形式筛选、报价、字段来源、数据质量与历史。

不做跨平台身份合并、数值口径换算、报价币种推断、评分推荐、导出、投放或采集契约变更。
