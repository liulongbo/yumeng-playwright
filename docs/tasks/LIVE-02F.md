## 目标与范围

在 LIVE-02 已完成的「直播广场关键词/达人 ID 采集」之上，新增真实筛选能力：

1. 巨量星图直播广场：内容「时尚」、达人性别、所在地域、粉丝量级、个人认证、直播间观众画像、粉丝画像、近期直播场次、平均观看人数、平均观看人次、ACU、PCU。
2. 磁力聚星直播广场：内容分类「美妆/美食/时尚」、粉丝画像、观众画像、预期观看人数、最高在线人数、预期 CPM。
3. 前端可选择/清除/提交筛选；后端计划、契约、Adapter、分页/恢复全程携带并真实应用。
4. 直播任务允许「仅筛选条件」创建；关键词/ID 变为可选；全空仍拒绝；短视频规则不变。
5. 两平台「时尚」真实采集闭环为强制验收项；其他筛选按真实页面交互 + 请求 + 结果核对验收。
6. 直播 70 位上限、任务中心、执行单元、数据隔离不变；短视频零回退。

不包含：

- 短视频筛选/采集行为变更。
- 新任务中心/执行单元/队列/Profile/迁移。
- 直播定时更新。
- 未在本次清单内的星图/聚星筛选器（例如聚星所属行业、星标推荐等）。
- 改造 LIVE-02 已完成的数据模型与读模型。
