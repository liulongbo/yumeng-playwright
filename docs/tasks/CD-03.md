## 目标与范围

按用户本轮要求，在**不改采集流程、不改数据库结构、不改快照与字段观测选择规则**的前提下，只调整「达人详情页面 → 左侧信息模块（身份资料卡）」：去掉 5 类展示（采集完整标识、观测时间、完整性状态、指定说明文案、数据来源区域），新增 3 个字段（星图ID、性别、介绍），调整指标顺序与数量单位，并调换内容主题/行业标签顺序。

包含：左栏信息架构、顺序、单位格式化、字段联通（达人详情 API 增加 1 个只读字段）、空值与长文本处理、局部样式、针对性测试与真实浏览器验收。

不包含：采集契约与解析（Parser/Adapter）、Scheduler/Queue/Worker、登录与会话、数据库 Schema 与迁移、历史索引回填（D3）、达人库精选作品封面授权（D4）、达人库列表页与其"采集完整/数据不完整"标签、右侧 5/6 个业务分区的内容。**未执行任何数据库 Schema 修改、迁移或数据回填。**

### 用户确认（2026-10-15）

1. **数量单位**：选 A —— `n ≥ 10,000` → 万（1 位小数）；`1,000 ≤ n < 10,000` → k（1 位小数）；`n < 1,000` → 原数。理由：与参考图及巨量星图实际口径一致（平台自身把 `粉丝 1,351,784` 显示为 `135.2w`）。原始规则中"1000–10000"的空白区间按 k 补齐。
2. **性别编码**：选 A —— `2 = 女`（2026-10-14 线上已确证）、`1 = 男`、`0 = 未知`；`1`/`0` 在代码注释与证据中标注"常规编码，未经本项目线上复核"。
3. **删除边界**：同意 4 点处理 —— ①删除左栏「数据来源」入口与其在左栏内的抽屉渲染；②改写底部快照行为只保留快照信息、去掉对已删区域的指引；③达人库入口的指定说明文案（4.9）删除，任务入口的快照语义提示保留（不在点名范围）；④原「平台 ID」复制按钮改为昵称下方的「星图ID」。
