## 2026-10-06 真实采集打通与字段缺口（宠物 · 22 位）

新账号下首次真实采集：22 位达人、6 个主页模块全部 `COLLECTED`（模块级 131 成功 / 1 失败），67 条快照落库。字段级覆盖率 **74.2%**（996/1342），**"主页完整"0/22**，缺口已分类：`MODULE_TIMEOUT` 128（模块超时预算偏紧）、`RESPONSE_UNCORRELATED` 114（模块内增量加载的响应关联规则）、`MISSING_SOURCE` 63（缺源字段口径待登记）；另有一次 `RESPONSE_SCHEMA_MISMATCH` 把整任务打成 `FAILED`，建议改为模块级降级。字段字典逐项对照（U04）仍未完成，本卡保持待验收。报告见[宠物 22 位采集效果测试报告](../evidence/pet22-crawl-test-2026-10-06.md)。

## 目标与范围

按技术方案第 6 章实现达人主页资料采集：验证候选主页与身份 → 按模块注册表顺序逐模块（注册观察 → 进入标签页/入口页与展开 → 等待业务就绪 → 读取响应与必要 DOM → 解析校验 → 写模块观测与检查点）→ 基础门槛成立即幂等计入有效数并保留草稿 → 可选模块失败仍保留该达人。  
包含：模块注册表与版本化检查点、身份核验、字段字典与标准化、字段状态与缺失证据、模块覆盖与完整性、来源冲突、模块恢复与新观测、证据引用。  
不包含：前端与产品 API、P1、F06 精选作品与封面存储、F09 手动刷新的产品入口、F10/F11 远程维护与代理池运维、真实字段字典核验。

## 验收清单

- [x] 主页身份与最低有效资料：主机/路径范围校验（含重定向后复验）、页面身份字段与候选平台 ID 核对；基础门槛为"已核验身份 + 身份匹配主页 + 昵称读取成功"，昵称不参与去重。
- [x] 模块注册表（§6.2.2）：模块标识、顺序、基础/可选标记、入口页面、标签页/展开动作、就绪条件（含必须消失的加载提示）、请求契约集合、DOM 契约、字段字典、模块级缺失/权限/空态证据、逐模块超时、检查点版本。
- [x] 逐模块执行与响应关联：一个模块的必需/可选响应分别声明并各自负责字段；必需响应超时→对应字段失败且保留已成功字段；不因"收到一个接口"判整模块完整。
- [x] 字段字典与标准化：数值/下界/近似/百分比保留原文、单位与精度；报价关联币种与合作形式；`—`/空串/占位符不得变为 0；来源与观测时间随字段保存。
- [x] 字段状态与证据：`COLLECTED`/`NOT_PROVIDED`/`NO_PERMISSION`/`NO_DATA`/`FAILED`/`NOT_ATTEMPTED` 各有依据；元素未找到不等同于平台未提供；模块级证据成立时可完成检查。
- [x] 来源冲突：注册了对照规则的双来源不可解释冲突记 `FAILED`+`SOURCE_CONFLICT`，不选择一个值覆盖；备用来源仅在登记条件下回退并保留回退原因。
- [x] 事务与门槛：基础资料、草稿引用、任务关联与有效数在同一事务幂等提交；后续可选模块失败仍保留该达人；迟到/旧尝试写入被租约与尝试版本拒绝。
- [x] 恢复：复用已提交且无失败的模块观测，只重采不完整模块并生成新 `module_observation_id`，不覆盖原观测、不混成同一观测时点；检查点版本不兼容时停止。
- [x] 离线单元、契约、存储及恢复验证通过，证据可查。
- [ ] 实机核验：按真实字段字典逐项对照页面（U04），确认字段值、单位、周期与缺失原因。
  - 已核验（2026-09-27，真实账号二，2 位达人）：`basic` 模块 9 字段逐项对照页面——`platform_creator_id`（响应 `id`，与主页 URL 段一致）、`nickname`（`nick_name`，与页面身份块一致）、`avatar_uri`、`followers`（`follower`，`unit=count`）、`gender`、`mcn_name`、`content_theme_labels`（列表 3 项）为 `COLLECTED` 且带来源/路径/观测时间；`city`/`province` 平台返回空串 → `NO_DATA`（未伪造）。
  - 已登记但未完成实机验收：商业与报价、传播、种草、履约、转化与本地销售已经进入 6 模块/61 字段注册表，并通过结构化解析及持久化离线测试；当前账号下的页面名称、单位、周期、编码和值到数据库的逐项对照仍待执行。粉丝画像、创作能力和个人介绍仍为数据源待确认；入口页跳转后的 DOM 身份复核缺口保留。
