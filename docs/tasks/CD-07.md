### 开发前调研结论（2026-10-15）

- 该模块只在**达人库入口**的 `CreatorLibraryDetailPage` 内渲染（`frontend/src/pages.tsx` 的 `historyChapter`
  第二个 `<section className="panel library-detail-panel history-panel">`），标题「系统采集历史」。
- 它消费三样前端状态：`history` 查询（`GET /api/creator-library/{id}/history`）、派生值
  `indexed` / `totalSnapshots` / `missingIndex`；这三样**只被该模块使用**。
- 该接口与 `CreatorLibraryHistory` DTO 仍由后端提供、仍被 `api.ts` 导出；本轮**只解除页面消费**，
  不删端点、不改 DTO、不改数据库（LIB-01 的历史索引表与数据保持原样）。
- 任务入口的「报价与历史」章节内容来自本任务快照的报价观察，**不含**该小模块，不受影响。
