# F04：平台筛选、搜索与候选发现

状态：待验收  
更新时间：2026-09-29T14:56:37+08:00

## 目标与范围

按技术方案第 5 章实现 P2-1：取得执行单元租约 → 校验线路/登录身份/能力版本 → 重建并回读原条件 → 增量发现候选（有序、去重、首次位置）→ 逐位采集 → 按目标数/搜索耗尽/预算暂停停止。  
包含：搜索契约与注册表结构、条件执行与回读、操作/响应关联、分页与终点、游标失效重扫、扫描与主动预算、候选有效性计数、诊断记录、搜索耗尽证据。  
不包含：前端、P1 需求转换、F05 主页字段实现、F06 精选作品、F09—F11、采购与生产发布。

## 关联与依赖

前置：BASE-01、UNIT-01。功能：F04。验收：T02、T04—T06、T13—T16、T31—T35。待验证：U02（筛选枚举/填写/回读/组合）、U04（分页、终点、身份与页面定位）。

## 验收清单

- [x] 搜索契约与版本化注册表结构实现：`SearchSpec` 含入口、重置/填写/翻页动作、就绪与必须消失的加载提示、回读定位、请求契约、结果路径、分页方式、游标续用；注册表发布门槛校验引用完整性。
- [x] 条件执行与回读：清理残留 → 执行本次条件 → 回读必须与 `FilterPlan` 一致，不一致抛 `PLATFORM_CONDITION_MISMATCH` 且不写入候选。
- [x] 响应关联：操作前注册观察范围，按方法/主机/路径/请求参数/响应身份关联，重复或无法归属的响应拒绝而非取最近一次；监听在操作结束后释放。
- [x] 有序发现与去重：平台顺序保存、跨页去重保留首次位置、已见身份每段只占一个扫描槽、目标 20/200 停止、无效候选补位、返回不超目标。
- [x] 停止条件：经验证的终点信号记录耗尽证据；零结果记为空成功；游标循环抛 `PLATFORM_PAGE_CHANGED`；扫描/主动预算用尽置 `PAUSED_BUDGET` 且不谎报耗尽。
- [x] 游标失效恢复（§5.2.3）：中途失效时在原条件下从起点重扫，保留已见身份与首次位置，记录搜索代次与重扫原因，且不禁用整个契约版本。
- [x] 无身份候选按 §5.2.2 记为诊断、跳过、不计有效数，不按昵称去重或拼接主页。
- [x] 离线单元、契约、存储与恢复验证通过，证据可查。
- [ ] 实机核验：真实账号下的筛选枚举、内容关键词模式、分页与终点、访问节奏（U02/U04）。
  - 已核验（2026-09-27 真实账号二）：**内容关键词模式**（内容找人 tab 回读、`search_param.keyword` 与 `search_param.seach_type=3` 关联、条件回读一致）；首页结果契约（`authors[]` 20 条、`id_path=star_id`、`pagination.has_more/page/limit`）；达到目标即停止且不谎报耗尽（`search_exhausted=false`）。
  - 未完整核验：筛选枚举与组合（合作诉求/匹配度/性价比/主题推荐）、第 3 页及以后和分页终点（AUTO-01 已实证第 2 页）、访问节奏/限流阈值（`action_interval_seconds=2.0` 为保守值）。
