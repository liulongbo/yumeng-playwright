## 2026-10-12 P2 采集 Worker 派发崩溃修复 + 真实采集端到端验证

**缺陷（DEF-05，已修复）**：启动 `make collection-worker` 立即崩溃（exit 2），异常为 `temporalio.service.RPCError: workflow execution already completed`，位置 `backend/src/xingtu/worker.py` 的取消收尾循环（`describe()` 判定 RUNNING 后 `signal()`，工作流在两步之间已完成）。异常从 `dispatch()` 冒出并终止 `run_worker()` 的 `while True`，**整个采集消费者死亡**；与 Intake Worker 此前同类缺陷一致。
