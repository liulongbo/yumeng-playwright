## 目标与范围

将平台安全验证从普通登录等待中拆分出来：检测后立即停止采集并保留同一浏览器会话、租约和检查点；仅在验证元素连续消失 5 秒且账号、受保护页面与 SessionHealth 均有效时自动续跑；达到达人/任务次数上限或 15 分钟超时时，以部分完成终止并保留已持久结果。

包含独立 ChallengeHandler、任务/执行单元状态、检查点计数与摘要、产品 API/页面展示、恢复幂等和重复请求减量。不包含滑块破解、轨迹模拟、验证码打码、隐身伪装、代理/账号轮换或非官方私有接口。

## 验收清单

- [x] 安全验证未解除时，应用不发起导航、搜索、模块、精选集合或封面业务操作（离线/合成路径验证；真实平台自然挑战仍待验收）。
- [x] 验证元素短暂消失不会恢复；连续稳定至少 5 秒且账号、受保护页面、SessionHealth 全部有效才恢复（离线专项测试通过）。

- [x] 单次等待默认 15 分钟，超时以 `SECURITY_CHALLENGE_TIMEOUT` 部分完成。
- [x] 账号不一致或会话失效以明确安全验证原因部分完成，已持久结果可查询。
- [ ] 恢复沿用同一 BrowserHost/Context/Page/租约，真实恢复仅增加一次 session_version。
- [x] 旧检查点具备默认值兼容，Workflow 新分支使用版本补丁保护；无数据库迁移。
- [x] 产品任务详情展示等待验证、次数、当前达人、等待时间、是否需人工、监测状态、终止原因与已交付说明。
- [ ] 恢复跳过已完成达人、模块、精选集合与已存封面；合成挑战恢复场景重复业务请求相对旧路径下降至少 50%。

- [x] 实现与文档不包含任何验证码破解或平台安全机制绕过能力。
