## 目标与范围

在本轮用户明确的两项范围内调整达人详情页，**只改前端展示与字段联调，不改任何流程**：

**一、「履约能力」模块**：去掉「行业订单分布」「行业播放分布」「合作行业分布」三个模块的页面展示。

**二、「连接用户」模块**：
1. 去掉「连接用户规模与粉丝增长」模块；
2. 把「近 30 日粉丝总数」与「近 30 日连接用户（平台窗口口径）」**合并为一张双轴趋势图**——左轴连接用户数、
   右轴粉丝数、X 轴时间，鼠标移到任一时间点可同时查看两者（按用户提供的参考图）；
3. 去掉「近 30 日粉丝日增量」。

包含：`FulfillmentPanel` 精简、`AudiencePanel` 结构重排、新增可复用 `DualAxisTrend` 双轴图组件与样式、
针对性前端测试、真实浏览器验收与文档回写。

不包含：采集契约与解析、Scheduler/Queue/Worker、登录与会话、数据库 Schema 与迁移、数据回填、
后端任何改动、其他章节（商业能力/创作能力/报价与历史）的改动。
**未执行任何数据库 Schema 修改、迁移或数据回填。**

### 开发前调研结论（2026-10-15）

- 两个趋势序列的真实来源与形状（真实开发库只读核查，达人 甄选聊车）：
  - `modules.fans.fields[]` → `fans_daily_trend`，`value.data[] = {date, fans_cnt}`，30 点，窗口 2026-09-14 → 10-13；
  - `modules.fans.fields[]` → `connection_daily_trend`，`value.data[] = {date, value}`，30/31 点，窗口 2026-09-13 → 10-12。
  - **两个窗口相差一天**，因此两条线在共享时间轴上各取各的点；缺失日期在图上留空，**不补造数值**。
- 两条序列量纲差异很大（连接用户 23,439,854 ≈ 2344.0万；粉丝 1,353,611 ≈ 135.4万），
  **不能共用一条 Y 轴**（会把粉丝线压平），因此左右轴各用各的刻度，不相加、不归一化。
- 即将移除的三个履约字段在 API 中仍返回 `COLLECTED`（`industry_order_distribution` /
  `industry_play_distribution` / `cooperation_industry_distribution`），本轮只解除页面挂载，**不删数据、不删端点**。
