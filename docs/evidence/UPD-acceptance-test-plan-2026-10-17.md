# UPD 功能验收测试计划（2026-10-17）

> 范围：达人手动更新、周期性更新、统一任务中心、统一执行单元池、优先级/冲突、数据与历史、正常采集回归、异常恢复。
> 方法：单元测试、隔离 PostgreSQL 集成测试、API/DB/Temporal/Worker 证据、项目既有 Playwright MCP stdio 客户端驱动真实 Chrome；不修改业务代码、生产 Schema、真实执行单元或凭据。
> 说明：harness 未直接暴露 `mcp__playwright__*` 工具；经检查项目存在 `scripts/acceptance/mcp_client.py` 与 `~/.codex/config.toml` 的 Playwright MCP 配置，使用同一 MCP server（`@playwright/mcp` 1.62.0-alpha-2026-06-29、本机 Chrome）作为传输客户端，不替换为其他浏览器自动化栈。
