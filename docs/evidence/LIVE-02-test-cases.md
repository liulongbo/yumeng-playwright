状态：第一阶段编写，第二阶段补充 70 专项后共 85 条；第三阶段执行结果 **67 PASS / 6 BLOCKED / 12 NOT_RUN**（逐条回填见表格）

关联：[LIVE-02 任务卡](../tasks/LIVE-02.md)、[PRD](../prd/LIVE-02-live-square-collection.md)、[技术方案](../design/LIVE-02-live-square-technical-design.md)、[影响分析](../design/LIVE-02-compatibility-impact.md)
执行原则：先写用例再执行；真实平台只使用授权账号与小样本；不以 Mock/接口调用代替真实浏览器验收；失败保留证据，不删除/降低断言。

## 1. 目的、范围与边界

覆盖：

1. 两平台直播广场采集（入口、关键词/ID、任务提交、执行、终态）。
2. 分页、多达人、去重、边界。
3. 字段解析、入库、完整度、空值/无权限/不编造。
4. 直播与短视频数据隔离；同一达人两场景；跨平台身份隔离。
5. 达人库直播列表、直播详情、场景切换、最近更新。
6. 手动更新直播、视频更新回归、在途/重复/失败不清空。
7. 统一任务中心、执行单元复用、同平台互斥、跨平台并行。
8. 两平台短视频回归、定时更新不受影响。
9. 异常、失败、重试、继续、取消、权限、挑战。

不在本清单内：直播筛选器逐项实现（本次只调研）、直播定时更新、直播榜单、超过 70 位的直播任务、跨平台合并。

## 3. 状态与类型定义

状态：`PASS` / `FAIL` / `BLOCKED` / `NOT_RUN` / `NOT_APPLICABLE`。  
类型：

- **单元/组件**：纯逻辑/前端组件，离线。
- **隔离集成**：真实 PostgreSQL 随机 schema + 合成 Adapter/BrowserHost，不访问平台。
- **真实 API/DB**：真实 FastAPI + 隔离/主库只读/授权写入。
- **真实浏览器端到端**：Playwright MCP + Chrome + 真实平台 + 真实任务。

所有真实任务必须记录：任务 ID、平台/场景、目标数、创建/终态时间、有效/发现/快照计数、执行单元、失败原因、DB 核对、页面截图。
