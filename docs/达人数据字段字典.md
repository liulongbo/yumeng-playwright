# 达人数据字段字典（巨量星图）

> 审计时间：2026-10-13；来源：`contracts/douyin_xingtu.verified.json` 与 `xingtu_development.public.creator_snapshots.payload` 的只读结构审计。样本为 11 位平台达人、39 份快照。本文不含昵称、平台 ID、链接、作品文本或具体指标值。

## 读法与边界

- 注册表共有 **8 模块 / 81 个业务字段**。快照中额外的 `fans.__module_failure__` 是失败诊断，不是业务字段。
- 实际字段统一封装为 `FieldObservation`：含 `status`、`observed_at`、`source_*`、`unit`、`period_label` 与 `value`。`N` 是实际观察到的 `NumericValue` 对象；`S` 是字符串或字符串数组；`J` 是 `StructuredValue.data`。下表的“示例”均为实际 JSON 形态的脱敏结构，并非虚构业务值。
- `C` = 写入巨量星图当前检索索引；`H` = 写入巨量星图快照索引；`Q` = 写入报价观察表；`J` = 只保留现有快照/当前投影 JSONB。`C/H/Q` 仅在字段 `COLLECTED` 且比已有来源新时写入。
- `raw` 后缀表示平台原值：不推断币种、缩放系数、百分比语义或跨平台可比性。所有“未确认”字段仍可按平台原样展示，不能作为跨平台统一筛选条件。

### 2026-10-14 实证更正：`fans.*` 四个字段是粉丝数据，不是连接用户数据

核对 78 份 `creator_snapshots.payload` 与 `contracts/douyin_xingtu.verified.json` 的 `source.request_key` 后确认：

- `fans_daily_trend` / `fans_daily_delta` / `fans_growth` / `fans_growth_rate` 均来自平台接口 `get_author_daily_fans`（`request_key=daily_fans`，路径 `daily` / `delta` / `fans_growth_v2` / `fans_growth_rate_v2`，叶键 `fans_cnt`）。
- `fans_daily_trend` 末值 1,353,611 与同快照 `basic.followers` 1,351,784 同量级且单调递增，相邻两日差值等于 `fans_daily_delta` 当日值（如 1,328,625 − 1,327,473 = 1,152 = 当日 `delta`）。
- `fans_growth_rate` = 196 与同快照 `monthly_follower_growth_rate.amount` = 0.01969004266000137 满足 `196 ≈ 0.01969004 × 10000`（49/49 快照成立）→ 月涨粉率百分比 = 该小数 ×100。
- 真正的连接用户序列是 `connection_daily_trend`（`request_key=daily_link`），其**末点恒等于 `monthly_connected_users`**（49/49 快照相等），30 点求和无业务含义。
- `connection_funnel` / `seeding_link_structure` 的 `link_struct` 在 67/67 份快照满足 value(1)+value(2)+value(3)+value(4) = value(5)，而 `monthly_connected_users` 的注册来源正是 `link_card.link_struct.5.value`（契约内），故阶段 1–4 是互斥分层、阶段 5 是合计。**2026-10-14 线上读取确认**：平台把该结构写作"连接用户漏斗"，实际渲染为"了解 / 兴趣 / 喜欢 / 追随"四层明细 + "连接用户数"合计（线上 12,090,818 / 6,709,919 / 4,958,875 / 5,937，合计 23,765,549），四层之和等于合计。因此页面按平台分层名称呈现，不使用漏斗图。

## 观察到的缺口

当前样本已验证 JSON 形态，不等于所有业务口径已定义。尤其是 CPM/CPE 的币种与缩放、互动/完播值的比例尺度、报价枚举和 `connection_funnel` 阶段含义均不进入统一字段或跨平台计算；一期只保存平台原值及来源。新增平台时另建该平台自己的字段字典和专属映射，不能复用这些名称来假定同义。
