**根因（已验证，两个独立条件）**：① 产品入口独有的常驻 P1 Intake Worker 没有运行，`dispatch_intakes()` 从未执行；② 缺少 `DEEPSEEK_API_KEY`，该 Worker 启动即 `DEEPSEEK_API_KEY_REQUIRED` 退出。真实样本 `3c96c78a-77f8-4e11-8081-953b12deae91` 在 `RECEIVED` 停留 **7 小时 8 分**（`sent=false`、`updated_at == created_at`、0 model run、0 plan）。脚本链路起始即 `QUEUED` 且使用人工 `FilterPlan`、不依赖模型，因此天然不受该缺陷影响；两条链路的第一处实质差异就是「前端多需要一个常驻 Intake Worker，且该进程此前不在任何编排或启动步骤中」。缺消费者时系统没有任何失败面，用户无法区分「正在转换」与「无人接管」。

**已完成的最小修复**：

**"登录一次存活 1 个月"仍未达成**；会话存活上界未测（仅知至少存活约 20 分钟且跨越多次浏览器重启）。

撤回依据：① 原证据（[有界宿主真实运行](evidence/AUTO-01-bounded-host-real-run-2026-09-28.md) 第 3.1 节）**自述无法区分**"用户新登录"与"既有会话被接受"；② 当时的探针**只验证受保护元素可见、从未比对账号 ID**，而校验要求账号精确一致，故"会话失效"可能是测量假象；③ 用户日常 Chrome 首次登录后可 **7-8 天**免登录进入后台，反证平台侧持久会话可行；④ 但项目独立 profile 实测约 **45 分钟**即失效。两种观测并存，**真实存活时长未定**。

当前设计见 [DEC-013](decisions/DEC-013-structured-session-and-scoped-contract-health.md)：用 `SessionHealth` 和 `ReleaseDisposition` 取代布尔 `session_verified/needs_login`。每个新 Chrome 进程都必须实际验证受保护页、绑定账号、登录页/挑战和线路；正常关闭后分别进入 `READY`、`NEEDS_LOGIN`、`ACCOUNT_MISMATCH` 或 `SESSION_UNVERIFIED`，关闭未确认仍进 `QUARANTINED`。DEC-012 仅保留为历史记录。

**2026-09-29 实现验证**：`ruff`／`format-check`／`mypy` 通过；共 **178 passed**（105 单测 / 18 Browser Contract / 51 集成 / 4 E2E）。集成测试使用独立随机 schema；20/200 位连续采集为合成验证。迁移 006 已应用到本地开发库并确认版本 1—6。**未执行**真实 Profile、真实星图 5/10/20 位和长周期检查点，因此 Goal 1 与真实平台容量仍为待验收，而不是已完成。

## 7. 独立开发者如何持续使用

1. 每次选一张卡，先读规范、相关PRD章节、卡片与前置产物；让AI围绕完整验收闭环实施，不再另拆几十张小卡。
2. 开始/阻塞/开发结束/每批自动测试结束/本轮结束时，由负责的AI主动回写卡片，无需用户提醒。开发与测试分开会话时，收到MCP／工具结果的后续AI继续更新原卡片；具体执行[开发规范第4.5节](agent.md)。只有全部验收项、适用验证、证据及交接均齐全才标“已完成”，异步测试启动成功不等于通过。
3. 明确区分离线测试、真实平台验证、生产线路验证；离线通过保留成果，缺失实机项保持待验收。开发工作因必要资源确实无法推进才标阻塞。
4. 同步本页看板与tasks/README的状态；具体命令、通过/失败证据只在卡片或链接的证据文档维护。
5. 新需求先记录范围变更依据；不在一期加评分、导入导出、跨任务达人搜索、定时刷新或多平台。采购/付费/生产发布按既有授权边界执行。

下一次可直接使用（需用户手机在手以接收平台验证码）：

> 请继续执行 [docs/tasks/UNIT-01.md](tasks/UNIT-01.md) 的本地开发验证阶段。本地开发网络模式、`xingtu browser-check`、`xingtu research`、`make smoke-local` 已实现并实测；F06 的两组精选集合与封面管道也已离线实现。现在请唤起项目独立 profile 的 Chrome，我先人工完成星图登录；随后按真实交互登记会话、搜索分页、主页字段**与两组默认精选集合（含封面来源与 CDN 主机）**契约，用经核验条件完成 1—3 位小样本检索、落库核对与封面采集核对，并回写 UNIT-01/F04/F05/F06 与两个总览。保持未知平台能力关闭，保留生产线路验证门槛。
